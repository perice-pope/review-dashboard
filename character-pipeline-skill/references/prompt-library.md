# Prompt library

Fill `<trigger>` into each before use. Bracketed parts are the user's to tune.
These are starting points refined from real production — replace the generic
bracket guidance with the user's specifics during the run.

## Still — hero portrait
```
<trigger>, cinematic portrait, shallow depth of field, soft key light, [setting], [mood]
```

## Still — performance shot
```
<trigger>, playing [instrument], mid-performance, expressive, stage lighting, medium shot
```

## Still — everyday / in-world
```
<trigger>, [ordinary action — making coffee, on a couch, walking], natural light, candid, relaxed
```

## Still — wide establishing
```
<trigger>, full body, [environment], wide shot, [time of day] light
```

## Animation prompts (motion ONLY — the still carries the look)
```
subtle head bob to the beat, fingers moving, slow breathing, hair shifting gently, natural blinking, locked camera
```
```
slow turn toward camera, soft smile forming, ambient hair movement
```
```
walking forward, relaxed gait, environment parallax, handheld feel
```

## Shot-variety checklist (so output doesn't read AI-generic)
- Vary shot length — a 30s short wants ~20 distinct stills, not 4 long holds.
- Use insert shots — hands, a detail, a reaction — to hide seams and add rhythm.
- Mix distances — close / medium / wide on the same character.
- If the user has real footage, cutting it in next to animation lifts both.
